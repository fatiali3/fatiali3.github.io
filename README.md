# Web UI Clone Project - Personal Bio

## Overview
This project is a clean, responsive single-page web application cloned based on a modern personal portfolio/link-tree UI design.

## Features
- Fully responsive design built with HTML5 & Tailwind CSS / Custom CSS.
- Dark mode theme with structured layout sections (About, Skills, Projects).
- Deployed live using GitHub Pages.

## Project Structure
- `index.html`: Main HTML entry point.
- `css/`: Directory containing stylesheet files.
- `assets/`: Directory containing media resources.
- `AI.md`: Documentation of prompts used during AI generation & debugging.
