Problem Statement & Objectives

Modern web development often relies on bulky frameworks that introduce performance bottlenecks and accessibility oversights. The objective of this project was to design a lightweight, fully modular portfolio and case study platform using standard web APIs while guaranteeing WCAG compliance.

Technical Architecture & Modular Structure

The system decouples styles and scripts into discrete modules. Global tokens reside in variables.css, while view-specific rules are loaded independently to prevent CSS bloat.

Accessibility Implementation Sample

Screen-reader notification and live region handling are implemented via decoupled JavaScript modules:

// Dynamic ARIA Live Region update for form validation
function notifyScreenReader(message) {
    const liveRegion = document.getElementById('successMessage');
    if (liveRegion) {
        liveRegion.textContent = message;
        liveRegion.setAttribute('aria-live', 'polite');
    }
}

AI Workflow Integration & Methodology

Generative AI and LLM agents were integrated throughout the development lifecycle to streamline design and testing:

  • Code Scaffolding: Generating clean, semantic HTML5 boilerplate markup.
  • A11y Auditing: Simulating screen reader behavior and identifying high-contrast color pairings.
  • Refactoring: Modularizing monolithic CSS files into discrete, manageable sub-stylesheets.
